# 📘 دليل مسؤول ومدير النظام التشغيلي (Administrator Runbook)
## نظام إدارة الأشغال والخدمات الهندسية — بلدية كفرنجة الجديدة v1.0

---

### 1. إجراءات بدء وإيقاف وإعادة تشغيل النظام
- **بدء التشغيل العادي (Normal Startup)**:
  ```bash
  npm start
  ```
- **إيقاف النظام (Graceful Shutdown)**:
  إرسال إشارة `SIGINT` أو `SIGTERM` لضمان إغلاق اتصالات قاعدة البيانات وحفظ الذاكرة المؤقتة.
- **إعادة التشغيل (Restart)**:
  ```bash
  npm run restart
  ```

---

### 2. إدارة المستخدمين والأدوار والصلاحيات
- إضافة وتعديل حسابات المهندسين والموظفين تتم حصرياً عبر شاشة الإدارة المركزية `Settings/Users`.
- مصفوفة الصلاحيات ديناميكية بالكامل (Zero-Code Dynamic RBAC) وتطبق فورياً دون الحاجة لإعادة تشغيل الخادم.

---

### 3. الفحص الصحي والمراقبة الروتينية
- فحص الحالة العامة: `GET http://localhost:3005/health`
- فحص جاهزية المحركات: `GET http://localhost:3005/health/engines`
- فحص صحة قاعدة البيانات: `GET http://localhost:3005/health/database`
