# 🚨 خطة الاستجابة للحوادث التقنية والتشغيلية (Incident Response Plan)
## نظام إدارة الأشغال والخدمات الهندسية — بلدية كفرنجة الجديدة v1.0

---

### 1. تصنيف الحوادث ومستويات الاستجابة
- **المستوى 1 (P1 - Critical)**: توقف الخادم بالكامل، تعذر الاتصال بقاعدة البيانات، أو فشل المعاملات المالية.
  - *زمن الاستجابة الأقصى*: **15 دقيقة**.
- **المستوى 2 (P2 - Major)**: بطء استجابة شاشة محددة، أو فشل رفع مستند معين.
  - *زمن الاستجابة الأقصى*: **ساعة واحدة**.
- **المستوى 3 (P3 - Minor)**: ملاحظات تحسينية طفيفة أو تنسيق شكلي.

---

### 2. سيناريوهات المعالجة السريعة
1. **انقطاع قاعدة البيانات PostgreSQL**:
   - يتحول النظام تلقائياً إلى وضع الذاكرة المؤقتة المحلي (In-Memory Fallback) لضمان استمرارية الأعمال دون انقطاع، مع إرسال تنبيه في السجلات.
2. **محاولات تسجيل دخول مشبوهة**:
   - يتم تفعيل محدد معدل الطلبات (Rate Limiter) وتجميد محاولات الـ IP المعني تلقائياً وتسجيل الحدث في `observabilityService`.
3. **تلف أو تعذر قراءة مستند**:
   - استعادة النسخة المؤرشفة من مجلد `backups/` بناءً على البصمة الرقمية SHA-256.
