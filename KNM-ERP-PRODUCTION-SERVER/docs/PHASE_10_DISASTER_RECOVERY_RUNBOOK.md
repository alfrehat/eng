# 🛡️ دليل خطة الطوارئ والتعافي من الكوارث (Disaster Recovery Runbook)
## نظام إدارة الأشغال والخدمات الهندسية — بلدية كفرنجة الجديدة v1.0

---

### 1. الأهداف والمؤشرات التشغيلية (RPO & RTO)
- **مؤشر نقطة التعافي (Recovery Point Objective - RPO)**: **≤ 15 دقيقة** (الحد الأقصى لفقدان البيانات).
- **مؤشر زمن التعافي (Recovery Time Objective - RTO)**: **≤ 30 دقيقة** (الزمن الأقصى لعودة النظام للعمل بكامل طاقته).

---

### 2. استراتيجية النسخ الاحتياطي (Backup Strategy)
1. **النسخ الكامل (Full Backup)**: يتم يومياً في تمام الساعة 02:00 صباحاً لكافة الجداول والوثائق.
2. **النسخ التراكمي/الفوري (Incremental/Continuous Backup)**: تدوير وتوثيق الـ WAL Logs والتغييرات اللحظية.
3. **أرشفة الوثائق والمخططات (Document Archive Backup)**: نسخ متزامن لمجلد `uploads/` مع بصمات SHA-256 الرقمية.
4. **نسخ الإعدادات والتكوينات (Config Backup)**: نسخ ملفات الإعدادات والـ Schemas مع عزل وحجب الأسرار وكلمات المرور.

---

### 3. إجراءات الاستعادة والتعافي خطوة بخطوة (Step-by-Step Restoration)
```bash
# الخطوة 1: إيقاف الخدمات مؤقتاً لتجنب تضارب البيانات
npm run stop # أو kill للعملية الجارية

# الخطوة 2: استرجاع أحدث نسخة احتياطية معتمدة
node scripts/backup-restore-cli.js --action restore --file backups/latest_full_backup.json

# الخطوة 3: التحقق من سلامة البصمات الرقمية وتكامل الجداول
node scripts/test-phase10-database-hardening.js

# الخطوة 4: تشغيل حارس الإقلاع وفحص الجاهزية
node scripts/test-phase10-startup-guard.js

# الخطوة 5: إعادة تشغيل خادم الإنتاج
npm start
```
